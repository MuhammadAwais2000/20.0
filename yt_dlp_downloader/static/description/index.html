URL Attachment Downloader

Download media from YouTube and 1700+ sites, store it in Odoo, and play it instantly

Overview

URL Attachment Downloader helps your team collect online media into Odoo in one click. Paste a public media URL, download it with yt-dlp, store it as an Odoo attachment, and preview/play it with the built-in OWL media player.

Note: Requires yt-dlp and ffmpeg on the Odoo server. See the Installation section below.

Key Features

  • URL-based download from YouTube and many other yt-dlp supported websites
  • Format options: Best video + audio, Video only, or Audio only
  • Automatic title fill from the source media metadata
  • Built-in media player (video/audio) on the form view
  • Automatic attachment storage in Odoo filestore
  • Download tracking: status, extractor, duration, file size, MIME type
  • Error reporting with clear messages when a URL is unsupported
  • Chatter history on every download record

Supported Sources

Works with public media URLs from popular platforms, powered by yt-dlp extractors.

  • YouTube / YouTube Shorts
  • Vimeo
  • Twitter / X
  • Facebook / Instagram / TikTok
  • SoundCloud
  • Dailymotion
  • Twitch clips / VODs
  • TED , Reddit , Bandcamp , and many more

Support depends on yt-dlp extractors and website availability. DRM-protected platforms (for example Netflix / Disney+ / Amazon Prime) are not supported.

How to Use

  1. Open URL Downloader → Downloads.
  2. Click New and paste a public media URL.
  3. Select a format (Best video + audio / Video only / Audio only).
  4. Click Download.
  5. When status is Downloaded, use the Media Player section to play the file.

Installation & Dependencies

After installing this app from Odoo Apps, complete the server-side setup below. These dependencies are required for downloads to work on your Odoo server.

1) Odoo Apps Dependencies

Installed automatically: base, mail, web

2) Required Python Package

Install yt-dlp on the same Python environment used by Odoo: 

pip install -U yt-dlp

# If your OS blocks system pip:
pip3 install -U yt-dlp --break-system-packages

3) Strongly Recommended System Package

Install ffmpeg to merge video + audio streams (needed for many YouTube downloads): 

# Debian / Ubuntu
sudo apt-get update
sudo apt-get install -y ffmpeg

4) Restart Odoo

Restart your Odoo service after installing the packages, then open URL Downloader → Downloads.

Docker Example

docker exec -u root YOUR_ODOO_CONTAINER pip3 install -U yt-dlp --break-system-packages
docker exec -u root YOUR_ODOO_CONTAINER apt-get update
docker exec -u root YOUR_ODOO_CONTAINER apt-get install -y ffmpeg
docker restart YOUR_ODOO_CONTAINER

Technical Notes

  • Files are stored as standard Odoo attachments (ir.attachment).
  • External Python dependency: yt_dlp.
  • Recommended system dependency: ffmpeg.
