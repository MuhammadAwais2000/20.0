Sale Chain Dashboard

Visual flow map of RFQ → Confirmed Quotation → Sales Order → Invoices (Paid / Not Paid)

Overview

Sale Chain Dashboard helps sales teams understand the full customer document chain in one interactive board. Select a client and instantly see quotations, sales orders, and customer invoices linked in a clear flow map.

Key Features

  • Client selector — choose any customer and load their sales chain.
  • RFQ column — draft quotations (Request for Quotation).
  • Confirmed Quotation column — quotations sent to the customer.
  • Sales Order column — confirmed sales orders.
  • Invoice Not Paid — unpaid, partial, in payment, blocked, or reversed invoices.
  • Invoice Paid — fully paid customer invoices.
  • Click-through navigation — open any document form directly from a card.
  • Live counters — legend shows counts per stage.

How It Works

  1. Install the module (depends on Sales and Invoicing).
  2. Open Sales → Chain Dashboard.
  3. Select a client.
  4. Review the flow map and click any card to open the related record.

Technical Notes

  • Installable by copying the module into your addons path and updating the Apps list.
  • Dependencies: sale_management, account.
  • Access: available to Sales users.
